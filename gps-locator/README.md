# Garett GPS Locator 0.1.5
Android 8.1, native GPS + optional Android NETWORK_PROVIDER. Opening the app starts diagnostic sampling; stable fix does not stop diagnostics. Diagnostics continue while the activity is visible and stop when the activity is no longer visible. The selected 5–20 minute limit applies to SMS only. GPS subscription is renewed after 90 seconds without callbacks, without changing system settings. SMS requests continue independently with a bounded timeout and stop GPS when no diagnostics or requests remain. No continuous idle polling.
For SMS, open Settings and explicitly opt into unprotected GPS commands. WARNING: anyone knowing the watch number can request its current location. No PIN or phone list; use only on your own managed device with wearer awareness. Remote historical position lookup is disabled. Commands: GPS, GPS FAST, GPS STATUS, GPS STOP (cancels own request). Network fallback may require connectivity and vendor provider support.
Build with Gradle 8.7, JDK17, SDK34. Stable private signing key optional; debug signature may change across releases. Test on physical watch: launch auto-start, persistent fix, loss of callbacks/retry, screen-off SMS, SMS while diagnostics active, no-PIN consent, concurrent requests, network fallback, cleanup, battery.

Boot/update receiver records readiness after normal boot (after first unlock if applicable) or APK update, without starting GPS or a persistent service. Manifest SMS receiver wakes the process on demand. Launch once and grant permissions and explicitly enable SMS sharing; force-stop requires manual reopening. Vendor battery policies may block broadcasts; settings exposes battery optimization status and standard system settings. Verify with screen off, after swiping the task away, after reboot without opening app, and after overnight standby. No guarantee on untested Omnia OS.
