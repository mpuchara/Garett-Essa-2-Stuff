# Garett GPS Locator 0.1.3
Native Java application for Android 8.1 (API 27). No Internet permission or libraries. Install APK, launch once, grant SMS and location permissions, set a shared 6–12 digit PIN and explicitly enable sharing. Any valid phone number may query using the PIN; no allowlist. Keep Android location enabled. Append a space and the PIN to every command. After upgrading, configure a valid PIN to enable SMS sharing. Commands: GPS, GPS FAST, GPS STATUS, GPS LAST, GPS STOP.
GPS normally requires three fresh consistent readings spanning at least five seconds; 10 m target, 20 m after 30 s, 35 m after 90 s (marked weak). Timeout 900 s (configurable 300/600/900/1200 s), reports a fresh best-effort fix or explicit failure. Accuracy is Android's estimate, not a guarantee. SMS sharing stays off until enabled. Use only on devices you own/manage with wearer awareness.
Idle uses a manifest SMS receiver, no GPS polling. Manual diagnostics continue with screen off until timeout or explicit stop. The last satellite snapshot remains available in memory. Status bar notification is visible during acquisition. Android force-stop and vendor battery policies can prevent SMS delivery; reopen after force-stop. Hardware testing required.
Build: Gradle 8.7 / JDK 17 / Android SDK 34, run gradle :app:assembleRelease in gps-locator. CI can use GPS_KEYSTORE_B64, GPS_KEYSTORE_PASSWORD, GPS_KEY_ALIAS, GPS_KEY_PASSWORD secrets for a stable private signing key; otherwise APK is debug-signed and later updates may require uninstall.
Test: open app and enable permissions; SMS from different phones with correct/wrong PIN; open sky, indoor timeout, moving, screen off, overnight, reboot, SMS failure, check satellite views and battery. Not yet tested on physical hardware.

Network fallback: Android NETWORK_PROVIDER (if available/enabled) may use Wi-Fi and cell towers. No external lookup or new internet permission. Both providers start on demand. A fresh network fix may be sent after 30 s; send a final fix only if materially more accurate or no preliminary fix was sent. No stale cached locations presented as current. If GPS is disabled at startup, network-only acquisition is bounded to 60 s. System provider availability on Omnia OS is unverified; it may need internet and may not distinguish Wi-Fi from cellular. Test network availability, GPS disabled, indoor/outdoor, no data, both providers and cleanup.
